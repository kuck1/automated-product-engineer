# Parallel platform examples

`projection-receipt.json` is the handoff from an independent platform lane to the convergence gate. Replace every placeholder with reproducible artifact metadata. The semantic receipt produced by the executable template is narrower: it contains the feature and vector digests plus normalized scenario outcomes so Kotlin and TypeScript can be compared directly.

Do not use the receipt to pretend platform-only behavior is shared. Android and iOS still attach device or simulator evidence for lifecycle, accessibility, capabilities, auth, storage, and distribution. Next.js still proves server/client boundaries and production output.
