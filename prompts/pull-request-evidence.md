# Pull Request Evidence Prompt

Prepare a reviewable pull request for **[FEATURE]**.

Write a concise title and description that explain the concrete user problem, resulting behavior, architecture boundaries, data and fallback behavior, and material risks. Include exact validation commands and results.

Attach before/after screenshots for meaningful UI changes at desktop and mobile widths. Link the relevant source, tests, migration, and design decision. Confirm the intended base branch, clean worktree, mergeability, required checks, unresolved review threads, preview deployment, rollback path, and any follow-up intentionally left out of scope.

Do not describe abandoned approaches unless they explain a tradeoff a reviewer must assess.
