# Offline HTML Prototype Prompt

Create a polished, dependency-free HTML/CSS/JavaScript prototype for **[FEATURE]**.

It must run from local files with no build step, CDN, remote font, image, or network request. Make every meaningful state reproducible with URL query parameters or visible controls.

Include desktop and narrow layouts, keyboard navigation, focus behavior, reduced motion, loading, empty, validation, success, recoverable error, disabled, long-content, and boundary-data states. Keep geometry stable across sequential steps unless the content contract requires a change.

Finish with a state index that lists each URL, viewport, fixture, and the behavior it proves.
