# Responsive State Matrix Prompt

Define responsive behavior for **[FEATURE]** from content pressure and task priority rather than named device categories.

Create a matrix covering wide, intermediate, and narrow widths. For every region specify:

- what remains visible;
- what wraps, stacks, scrolls, condenses, or moves;
- minimum useful width and overflow behavior;
- touch target and input-mode changes;
- long labels, localization, dense data, zero values, and error content;
- modal, drawer, popover, table, chart, and navigation behavior where applicable.

Include desktop and mobile reference frames plus at least one transition-width frame that proves the layout does not clip or hide required actions.
