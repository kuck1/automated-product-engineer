# Typed Component Contract Prompt

Turn the approved design into a reusable React and TypeScript component contract.

Return:

- component hierarchy;
- exported prop and callback types;
- supported variants and states;
- accessibility roles, names, focus rules, and keyboard behavior;
- slots for copy, configuration, server data, analytics, navigation, and mutations;
- examples for default, loading, empty, error, disabled, selected, and long-content states.

Keep local interaction state inside the component. Pass server state and side effects through typed adapters. Reuse the existing design system and explain any new primitive or semantic token before adding it.
