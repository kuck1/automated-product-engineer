# Motion and Interaction Specification Prompt

Specify the interaction and motion contract for **[FEATURE]**.

For each interaction list the trigger, precondition, state change, visual response, duration, easing, interruption behavior, focus movement, announcement behavior, and reduced-motion alternative.

Cover hover, focus-visible, pressed, selected, expansion, dismissal, Escape, outside click, back, retry, optimistic updates, rollback, completion, and route changes where relevant.

Motion must explain hierarchy or causality. Remove ornamental animation that delays the task, causes layout shift, or hides state changes.
