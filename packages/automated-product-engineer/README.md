# Automated Product Engineer

Install a complete, local product-engineering reference system into an existing application:

```bash
pnpm dlx automated-product-engineer
```

[Explore the live reference site](https://automated-product-engineer-nextjs.vercel.app) · [View the package on npm](https://www.npmjs.com/package/automated-product-engineer) · [Read the source](https://github.com/kuck1/automated-product-engineer-nextjs)

The zero-flag install includes 13 adaptive agent skills, agent adapters, architecture and design-system guides, checklists, implementation templates, two full-stack case studies, Supabase examples, testing and CI patterns, screenshot automation, and retrospective fix-back material.

The reference kit is installed under `.automated-product-engineer/`; agent skills are also placed in the supported discovery locations. The host application does not import the reference directory at runtime.

See the [live reference application](https://automated-product-engineer-nextjs.vercel.app) for the interactive system and the [project repository](https://github.com/kuck1/automated-product-engineer-nextjs) for complete documentation.
