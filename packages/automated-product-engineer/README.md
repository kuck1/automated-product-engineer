# Automated Product Engineer

Install Auto's agent skills, design-system guidance, deterministic workflows, and verification tools into an existing application.

```bash
pnpm dlx automated-product-engineer
```

## Links

- [Website and live reference app](https://www.buildwithauto.ai)
- [Open-source GitHub project](https://github.com/kuck1/automated-product-engineer)
- [npm package](https://www.npmjs.com/package/automated-product-engineer)

## What it installs

- 13 adaptive agent skills with adapters for Codex, Claude Code, Cursor, Windsurf, GitHub Copilot, Orca, and generic agents.
- Architecture and design-system guides, implementation templates, checklists, and working examples.
- Deterministic testing, CI, screenshot, delivery, and retrospective fix-back workflows.

The reference kit is installed under `.automated-product-engineer/`; skills are also placed in each selected agent's discovery location. The host application does not import the reference directory at runtime.

See the [live reference application](https://www.buildwithauto.ai) for the interactive system and the [GitHub project](https://github.com/kuck1/automated-product-engineer) for complete documentation.
